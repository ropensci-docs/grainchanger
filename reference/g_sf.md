# Example grid (coarse_dat)

An example grid to show functionality when aggregating using an sf
object.

## Usage

``` r
g_sf
```

## Format

An sf object.

## Source

Sciaini M, Fritsch M, Scherer C, Simpkins CE. NLMR and landscapetools:
An integrated environment for simulating and modifying neutral landscape
models in R. Methods in Ecology and Evolution. 2018; 00:1-9.
https://doi.org/10.1111/2041-210X.13076

## Details

Generated with `nlm_mpd()` and converted to sf.
